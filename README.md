# usp-sweet-shop
# 🍰 Продавница слаткиша (Sweet Shop App)

Мобилна апликација за продају, резервацију и промоцију premium кондиторских
производа (мафини, торте, колачи), развијена у оквиру предмета
**Управљање софтверским пројектима**, Факултет инжењерских наука,
Универзитет у Крагујевцу.

> 📌 Овај репозиторијум / документ представља семинарски рад који је
> предметни професор оставио као **пример доброг рада за наредне генерације
> студената**. Структура, методологија и ниво детаљности могу послужити
> као шаблон за израду сопственог пројекта.

---

## 🎯 О пројекту

Апликација повезује традиционалне посластичарнице са савременим дигиталним
искуством куповине. Кључне вредности које решава:

- Увид у **стање залиха у реалном времену** (нема одласка у радњу по
  производ који је распродат)
- **Резервација** производа са временским слотовима
- **Google Maps** интеграција за проналажење најближе продавнице
- **Loyalty / gamification** систем награђивања верних купаца
- **Push нотификације** типа "Тек испечено" (geo-fencing)
- Напредни **admin panel** за управљање залихама, ценама и аналитиком

## 🛠️ Технологије

| Технологија | Намена |
|---|---|
| **Flutter** | Развој мобилне апликације (Android & iOS) |
| **Cubit / flutter_bloc** | State management |
| **Firebase** | Аутентификација и база података |
| **Google Maps API** | Геолокација продавница |
| **Stripe API** | Онлајн плаћање |
| **SQLite / Hive** | Локално складиштење и кеширање |
| **cached_network_image** | Кеширање слика производа |
| **flutter_svg, flutter_gen** | UI ресурси и иконице |

Архитектура апликације заснована је на принципима **Clean Architecture**
(Data / Domain / Presentation слојеви), организованим по *feature-driven*
приступу (`auth`, `catalog`, `maps`, ...).

---

## 🗺️ Методологија рада

Пројекат је реализован кроз **агилни приступ**, подељен у 4 главне фазе:

1. **Дизајн и UX стратегија** (2 недеље) – Figma прототип, custom theme
2. **Технички развој и имплементација** (6 недеља) – Flutter frontend, backend, Google Maps
3. **Тестирање и QA** (2 недеље) – Unit, Integration, UAT
4. **Deployment и подршка** (1 недеља) – Google Play / App Store, GitHub

Укупно трајање пројекта: **~11 недеља** (детаљан гантограм у прилогу рада).

## 💰 Финансијски модел (сажетак)

- Директна продаја производа
- Специјалне поруџбине (торте, поклон пакети)
- Loyalty / попуст програм
- Партнерства и промоције локалних произвођача

Процењена **нето месечна добит**: ≈ 960.000 RSD (на основу претпостављеног
обима продаје у Крагујевцу).
